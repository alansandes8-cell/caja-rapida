# Caja Rápida

App de caja para el celular: productos con stock, cobro en efectivo o transferencia con vuelto, historial de ventas, resumen del día y copia de seguridad.

Es una app web instalable (PWA): funciona sin internet y guarda los datos en el celular.

## Publicar cambios
Al cambiar algo, subí el número de `VERSION` en `sw.js` para que los celulares descarguen la versión nueva.
